# wunschliste[README.md](https://github.com/user-attachments/files/33914194/README.md)# Meine Weihnachtswunschliste 🎄

Eine schwarz-goldene Weihnachtswunschliste mit geschützter Admin-Oberfläche.

- Öffentliche Seite: `index.html`
- Admin-Seite: `index.html?admin=1`
- Admin-Passwort: das bereits für die Wichtel-Seite verwendete Passwort.
- Daten: Supabase-Tabelle `christmas_wishes`, Edge Function `weihnachtswunschliste-api`, Storage Bucket `christmas-wishes`.

## Kostenlos auf GitHub Pages veröffentlichen

1. GitHub → **New repository** → Name z. B. `meine-weihnachtswunschliste`, Sichtbarkeit **Public**.
2. `index.html` und `README.md` aus diesem Ordner im Hauptverzeichnis (`main`) hochladen.
3. Repository → **Settings** → **Pages** → **Build and deployment** → **Deploy from a branch** → `main` und `/ (root)` → **Save**.
4. Die öffentliche Seite wird unter `https://DEIN-NAME.github.io/meine-weihnachtswunschliste/` erreichbar, das Admin-Panel unter derselben URL mit `?admin=1`.

> Wichtig: Das Repository darf öffentlich sein, da dort **keine Geheimnisse** hinterlegt sind. Der Administrator-Zugang wird serverseitig geprüft. Bilder und Wünsche sind bewusst öffentlich. Bitte keine privaten Daten in die Beschreibungen eintragen.
